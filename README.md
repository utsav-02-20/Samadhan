## 📖 Overview

**Samadhan (समाधान)** is a unified civic governance platform that digitizes the complete lifecycle of public issue resolution. It enables collaboration between citizens, government departments, universities, and industry partners while ensuring transparency, accountability, and real-time tracking.

---

## 🌟 Key Portals

- **👤 Citizen Portal** — Report issues with GPS, photo evidence, anonymous public feed, and live tracking.
- **🏛️ Government Portal** — Verify complaints, assign departments, manage milestones, and monitor progress.
- **🏢 Department Portal** — Update field progress, upload completion evidence, and close milestones.
- **🎓 University Portal** — Submit research, AI solutions, and civic innovation prototypes.
- **🤝 Partner Portal** — Collaborate with government through funding, technology, and project execution.

---

## ✨ Core Features

- 🤖 AI-powered complaint categorization and department routing.
- 📍 GPS-based issue reporting with photo uploads.
- 🔐 Secure role-based authentication using Clerk.
- 📊 Real-time milestone and complaint tracking.
- ☁️ Cloud media storage with Cloudinary.
- 📱 Responsive multi-role dashboards.

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| **Frontend** | Next.js 16, Tailwind CSS, Clerk, Lucide React |
| **Backend** | Node.js, Express.js (REST APIs) |
| **Database** | MongoDB Atlas |
| **Media Storage** | Cloudinary CDN |
| **Deployment** | Vercel (Frontend) + Render (Backend) |

## 🚀 Quick Setup

### Clone Repository

```bash
git clone https://github.com/your-org/samadhan.git
cd samadhan
```

### Run Backend (Port 5000)

```bash
cd backend
npm install
npm run dev
```

### Run Frontend (Port 3000)

```bash
cd frontend
npm install
npm run dev
```
