# Features

## Authentication
- Secure role-based authentication using Clerk.
- Separate login portals for Citizen, Government, Department, and University users.
- Protected dashboards for each role.

## Citizen Portal
- Multi-step challenge submission form.
- Live GPS location detection with automatic retry.
- Photo upload for issue evidence.
- Anonymous challenge submission option.
- AI-assisted issue categorization.
- Downloadable PDF submission receipt.
- Dashboard to track submitted challenges and their status.
- User profile with submission history and community support.

## Government Portal
- View and manage reported challenges.
- Update challenge status and progress.
- Assign issues to relevant departments.
- Monitor district-wise civic issues.

## Department Portal
- Receive routed challenges.
- Verify and process assigned issues.
- Update resolution progress and SLA status.

## University Portal
- Receive innovation and research-related civic challenges.
- Review assigned challenges.
- Submit proposed solutions and updates.

## AI & Location Features
- AI-based challenge categorization.
- Smart routing to departments or universities.
- Reverse geocoding for district, subdivision, and address detection.
- Automatic retry when location detection fails.

## Dashboard & Tracking
- Real-time challenge status tracking.
- Community supporter/upvote count.
- Resolution history and analytics cards.
- Search and filter submitted challenges.

## PDF Receipt
- Generates an official challenge submission receipt.
- Includes challenge ID, category, location, timestamp, description, and evidence details.
